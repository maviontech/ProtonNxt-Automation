# Manage Members Test Suite

## MTM-001 - Manage Members page loads

After an authenticated admin opens `Teams > View Members`, the page shows the member search control and the list table with its expected columns.

## MTM-002 - Existing members are listed

The list contains at least one member and each visible row contains member details.

## MTM-003 - Member search accepts a name

The Manage Members search field accepts a member-name query.

## MTM-004 - Member search accepts an email

The Manage Members search field accepts an email query.

## MTM-005 - Global search accepts a query

The global search field in the page header accepts a query.

## MTM-006 - List and Cards view controls work

The user can switch to Cards view and return to List view, where the member table is visible again.
